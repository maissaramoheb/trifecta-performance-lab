# Source analysis and implementation basis

## Materials inspected

1. `alamwd-althhny-walasby-fy-alTrifecta.pdf` — 14-page internal course document focused on Cognitive / Neurophysiological Performance.
2. `qraah-aladaa-alkaml-fy-tdryb-alrmayh-3.pdf` — 27-page internal course document combining Learning Domains, the Trifecta, field examples, assessment gates, and references.

Both PDFs were text-extracted and every page was rendered for visual inspection. The documents share the same dark operational visual language and the same core framing.

## Source-derived framework structure

### Learning Domains

- Cognitive: Remember, Understand, Apply, Analyze, Evaluate, Create / Improve.
- Psychomotor: Imitation, Guided execution, Precision, Coordination / articulation, Stable / naturalized performance.
- Affective: Receiving / attending, Responding, Valuing, Organizing behaviour, Internalizing / consistent compliance.

### Trifecta

- Physical Performance: basic readiness, balance/control, progressive endurance, recovery, retention under pressure.
- Technical Performance: knowing the procedure, guided execution, accurate execution, linking steps, stable repeatable output.
- Cognitive / Neurophysiological Performance: SA, CLM, DMUS, WMTR, CFA, ERSI, MCC, RSVMI, FRFRC, SCR.

### Governing source rules

- Learning Domains build learning; the Trifecta diagnoses actual performance.
- Accuracy or a total score alone does not describe full performance.
- A successful attempt does not prove stable skill.
- Critical Safety Failure is a 100% gate and cannot be compensated by other scores.
- The correct intervention depends on the actual gap: explanation/check, demonstration/practice, load progression/recovery, or pressure/decision practice.

## Duplicated or potentially conflicting terminology

- The psychomotor source uses field-oriented “Guided execution” where Dave’s taxonomy is often translated as “Manipulation.” The application preserves the source’s field term and cites Dave only as the taxonomy basis.
- “Stable and naturalized performance” and “automatic commitment” are treated as progression anchors, not claims that behaviour is unconscious or impossible to disrupt.
- Technical Performance mirrors some Psychomotor stages. The application keeps them separate: Psychomotor asks how the skill is developing; Technical asks whether the observed output met the standard.
- The cognitive pillar is shown both as four phases and a five-step operational chain (see/understand, remember, decide/adapt, execute/control, sustain/recover). The application preserves the ten families and uses phase labels only as navigation aids.
- The 45/30/25 curriculum distribution shown in the source is contextual, not a universal weighting rule. It is not used as a default score. Safety remains an independent gate.
- “Neurophysiological” is retained as source terminology but bounded as practical human-performance observation, not clinical or neurological diagnosis.

## Source-derived versus applied recommendation

Source-derived content is marked “Internal source / مستند داخلي” in the interface. It includes framework definitions, progressions, example patterns, ten cognitive families, proposed metrics, and the safety gate.

Applied recommendations are explicitly marked. They include:

- builder validation warnings;
- one-variable-at-a-time station design;
- local evidence/assumption separation mechanics;
- simplified calibration consistency;
- device-local profiles and print/export formats;
- the rule to prefer Need More Data when the evidence cannot distinguish causes.

These recommendations operationalize the source but are not presented as independently validated scientific instruments.

## External research gaps and verification

The internal source cites the main foundations. Authoritative/original-source links were verified for:

- Endsley’s situation-awareness model;
- Sweller’s cognitive-load work;
- Arnsten’s review of stress and prefrontal function;
- Van Dongen et al. on cumulative sleep restriction;
- Harden et al. on structured station assessment.

The application states what each source supports and what it does not prove. It does not use decorative citations.

## Safety boundary

Examples stay at the level of safe training progression, cues, timing, observable compliance, station design, and assessment. The product excludes engagement tactics, room clearing, offensive procedures, detailed weapon manipulation, and clinical/personality diagnosis.
